# 执行参考：按需读取

规则以 [SKILL.md](../SKILL.md) 为准。开批按模板确认本批输入；其它小节按需参考，不增加逐站确认。

## 批次启动模板

各项都要有明确答案，可以从本批对话或已确认的工作区资料预填。只有发信获准时才需渠道和发件邮箱；「只投官网」「不发送」「无」都是明确答案，不把空白当成默认授权或确认。

```text
使用 $submit-producti-directories-merged，默认用 CDP，按清单顺序处理免费投递。

产品名称：
官网：
允许使用的子页：【列出网址 / 只投官网】
品牌资料位置：【工作区或文件路径】
浏览器配置：【本批使用的品牌浏览器配置】
本批自动化授权：【允许填表并提交 / 只允许预填】
官方联络邮件：【不发送 / 授权发送，并注明渠道和发件邮箱】
其他限制：【填写本批限制 / 无】
站点清单：【按顺序粘贴网址，或填写清单路径】
```

联系人、公司数据、社媒、账号和素材只从本批明确提供或私有工作区已核实的资料取用，不把实际资料写进通用技能。使用子页时采用真实功能名称与匹配素材，不为去重另造身份；缺图可取用官网素材或制作真实页面截图。登录邮箱、必填商务邮箱和授权收发邮箱各按用途使用，不相互替换。

## 浏览器连接与失败定位

- 复用已验证的工具和运行时。连接前确认当前 profile、调试端口和页面清单；CDP target 的 `page` 是标签页，`iframe` 单独处理。只连业务页，保持原会话。
- 模块、WebSocket 或 REPL（交互执行器）不兼容时，定位运行时和依赖；若有正常的独立脚本就复用，不反复试同一段代码。新脚本先做只读连接和页面读取。
- “未找到元素”先确认当前页面、iframe、弹层或刷新状态；超时先区分本机连接、加载中与站点报错。根据证据修正，再试一次有变化的操作；是否换电脑操作由当前授权和现场情况决定。
- 重试记录只写有用的错误、原因、改变和结果，不要求普通站填写诊断字段。任何换工具或重连都不会重置最终动作次数。

## 搜索不可靠

固定查询集见主技能。真实触发搜索并核验相关候选外链；重复查询仍给出同一批模糊结果时，不继续翻全站。补查有希望的后台或列表后记 `inconclusive`（未能确认）；没有搜索能力记 `not available`。已授权的直接尝试继续，未授权且影响提交时才问缺口。不得把超时、旧页面或“没看到”记成已去重。

同功能、不同域名的条目只是线索，结合真实出站网址和已有品牌资料判断是否为同一产品。确需用户确认同一组品牌或产品的关系时，合并受影响站点只问一次；结论明确后复用，未明确前不将它们记成已确认重复。

## 字段不持久、上传与刷新

先查可见的免费档、名额、必做互动及验证要求；后续步骤才显示的条件，在制作费时素材或最终提交前按需检查。按页面可见限制核对必填项、字数及格式（含 Markdown 标题或内嵌图片等）、分类、图片尺寸和大小。回读名称、网址、描述和必填项；上传等待成功、正常预览或按钮解锁，不重复上传/点击。确实超时保留进度交人工。

## 短暂回执

优先工具已有的事件、页面变化或即时读屏。回执可能一闪即逝时，可在点击前监听提交响应并在点击后短时采样，保存最早明确回执；采样在工具内完成，不把每次读页都变成模型往返。不要求所有站安装特定 CDP 函数或固定采样频率。
明确原生回执就记录；缺失或矛盾时再用网络响应、后台、邮箱、公开页中最有用的一项核验。无后台不是“未提交”；同页成功也不需要网址跳转。

用户明确要求不核验时不补查。有匹配的站点回执就保留已知状态；仅有用户明确报告时，引用消息并用 `submitted — user reported`；只观察到点击而无结果时，记 `submission outcome unknown` 并说明未核验原因。没有点击证据或用户报告时，保留当前未提交状态。均不因缺少回执自动重投。

## 官方联络邮件

先核验本批发送授权、指定邮箱的发件身份和站点官方 Contact/投稿/资源推荐来源；查记录和该邮箱的已发送、草稿等可用证据去重。正文用站点语言，说明真实产品、规范网址和相关性，请对方自愿考虑收录；不请求代发短贴、文章、dofollow 或排名保证。
发送前回读发件人、单一收件人、主题、正文和链接，CC/BCC 留空。本批已明确授权从指定邮箱发送时，直接发获准范围内的邮件，不逐封请示；工具如要求原生审批则按其处理，不改渠道绕过。每目标最多一封首封邮件，不自动跟进、不重发。记录渠道及发件、收件别名；草稿不是已发送，发送回执也不等于站方收到或接受。发送结果不明时，按需只读查撰写页、已发送副本或渠道回执。

## 人工接力

普通协议勾选：工具要求审批时，由用户处理原生审批，聊天不重复请示。工具明确拒绝代勾时，填好其余字段、保留原页，只请用户勾选对应项，先不提交；不换工具绕过拒绝。用户勾完后，回读状态并从原页继续。用现有记录注明「需人工勾选：工具限制」。

仅将当前可执行范围内的表单交接。先填已核实字段与素材，留在原验证页；字段被验证墙挡住时如实说明。用户完成验证后先读当前状态，有成功回执就收尾；需要验证码和提交连续完成时请用户立即提交，模型随后只读核验。短贴/长文编辑器不适用交接流程。

交接写清站点、原标签页、已填内容和剩余动作。「只允许预填」时交接提交本身，模型不代点。未点过最终提交就按首次处理；已点过时按授权核验，不要求用户再点。原页无法保留时写明原因和可恢复入口，不伪造保留状态。
