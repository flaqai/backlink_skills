# Pinterest 长期画板维护

围绕指定产品创作 Pin，根据目标市场的需求选题，按品牌画风呈现，按读者用途维护画板。每条 Pin 有独立的收藏理由和点进产品页后可尝试的操作。外链建设和真实读者访问同等重要。

## 启动任务

从对话和项目记录确认品牌或账号、目标产品页、本轮阶段和用户已定的范围。在 Sean 工作区查 `AGENTS.md`、`pinterest/board-maintenance.md` 和 `pinterest/boards.json`，其他项目沿用自己的记录。影响当前步骤的缺项一次问齐，未定的地区、语言和风格可在调研后建议。参考数量、画法、图片比例和交付形式按任务用途决定。

新选题进入调研与方案确认。只查市场、只交方案或只审查内容时，交对应结果。已确认的方案直接进入制作。局部修改沿用相关依据，按用户给定的范围修改和复核。已授权发布时，从核对账号、画板和最终稿开始。

可复制下面的模板，填入这次已知的信息。

```text
$pinterest-board-maintenance
品牌或账号【填写名称】
目标产品页【填写网址】
本次希望做到【查趋势／给画板和 Pin 方案／制作图文／验收或修改／发布】
其他已定要求【可选，如地区、语言、画板、条数或风格】
```

## 调研与选题

用浏览器调研时尽量复用同一张标签页，确需对照时少量加开。同批共用有效的依据，只补会影响选题、排序或画法的缺口。

- **四类依据。** 开放找题或做完整提案时，查目标地区的 **Top monthly trends**（月度搜索规模）、**Trends in the spotlight**（收藏走势）、**Moments**（活动时机）和 **Pinterest 社区**（创作者或平台人员的实际做法）。开放找题从未筛选的全类目月榜开始，用全类目上升榜（Growing trends）补查。用户限定题材时按其范围查，未指定市场时选有依据的主要用户地区。来源取不到或不适用时说明原因。
- **数据口径。** 优先用原生数据，必要时在获授权的工作浏览器里只读核验。用同地区、同时间窗和同筛选口径的周月变化或曲线判断升温、见顶和回落。区分搜索、收藏、预测和单帖互动。具体转折日期用带日期的数据支持，细分词缺曲线时可引用上一级走势并注明缺口。记录实际使用的榜别、地区、查阅日、截止日、关键词、筛选条件和原始链接。链接无法复现引用的数值时，附可取得的截图或导出。实际搜索量和转化需有独立证据。
- **同用途参考。** 看 Pinterest 或小红书的实际作品，判断读者要成品、灵感还是方法，再提取取景、光影、材质和缩图看点。可用一个主参考或多条相互印证，按需要对照不同作者及同板旧作。美甲优先看小红书等平台的爆款实拍，借鉴自然手势、取景和光线。用小红书样本时，在目标市场的 Pinterest 快查同类作品或关键词。把与题材有关的官方指南和创作者实作经验用到画面。 [Pinterest 创作指南](https://create.pinterest.com/en-gb/fundamentals/)
- **找全候选。** 开放选题时，通看本轮已读的榜单、收藏焦点和节日节点。比较月榜高位、多词支持的需求、跨类目热点、已有方向和用户点名的题材。主动找原有画板之外也适合品牌和产品的用途。同一用途的近义词归组，即使属于同一大类，读者用途或时机不同的也单列。给出代表词和近期走势，有月榜数据时列同口径的排名和指数。
- **覆盖拟做方向。** 在用户范围内，把有需求依据、时机合适且产品能提供具体帮助的方向都写成具体 Pin，放进同一份拟做清单。条数宁多勿少，各条有独立收藏理由。值得探索的同案列为试做，写清待验证的问题。按读者用途查可续更的旧板，适合长期做成系列的题材可提新板，再定条数和顺序。开放选题的方案提交前，从已查的原始榜单、收藏焦点和节日节点反查候选，再对照拟做清单。补上漏掉的可做方向，在同一份方案写清各组是拟做、试做还是暂缓。暂缓说明具体原因，因用途重复暂缓时指出对应构思或旧作。

## 开工方案与确认

完整方案在一处交代四类依据怎样影响取舍和画法，并列出拟做的 Pin、画板、条数、先后和本轮做到哪一步。另发确认摘要时保留影响决定的依据。新板写清用途、名称、可直接用的简介、封面方向和共同画风，续更说明如何接上旧作。画风用用户指定的风格、已核实的品牌作品或官方产品示例作依据，新尝试标为本轮提议。

每条 Pin 说清收藏后怎么用、缩图先看到什么、画面怎样体现品牌，以及点进目标页能试哪一步。需要时说明放大要看哪些细节。说明实际借鉴的案例或社区做法，原帖或精选卡链接可以按共用用途集中列出。核对目标产品支持的动作，承诺成品时写清规格和获取方式。相近构思和可比旧作并排看，按用途拉开构图、光色或设计。

只按参考作品试做时，给原帖或精选卡及拟做版本，交代归板和用途。第三方原图用于编辑、生成或发布时，核对许可覆盖实际用途并注明来源。

用户确认方案后开始制图、写文案或交办制作。按确认的用途和可见要求调整画法，超出确认范围的变动只确认涉及的部分。

## 制作、主控验收与交付

1. **制作主图。** 按确认的用途和画面看点选构图、比例、光色和工具，图上文字服务作品。涉及人体局部细节时优先用实拍底图，可用品牌自有或补拍素材、获准修改和发布的作者原图、许可覆盖本次用途的图库照片。按需局部修改，保留自然结构、比例、纹理和原有光影。美甲可只改甲色或纹样，保留手型和甲形。
2. **准备文案。** 画板名和简介说清用途，标题自然使用贴题的搜法，描述补充作品用法和适合在产品页试的动作。名称、简介、标题和描述默认省略品牌名。对照成图定稿，替代文字写可见内容。提示词按需要提供，有变体时说清改了什么和可见差别。标明样图实际来源，功能、费用、生成结果和商用说法需有证据。产品网址只填 Pin 的 Link 字段，商品标签按实际适用性处理。
3. **验收。** 用实际预览对照开工方案，先看信息流大小的看点，再放大核对品牌细节、结构和裁切。多张图和可比旧作并排看。核对文案、替代文字、目标 Link 和读者取得成品或开始操作的路径。人体局部细节检查比例、边缘、纹理和光影，美甲另查甲缘和反光。局部修图做同尺寸前后对照。其他修改核对受影响的内容，同步稿源和预览，包括图上文字与替代文字。留待公开页核验的事项标明。
4. **交最终稿。** 完整图文提供可取用的上传图、标题、描述、替代文字、主题词候选、目标 Link、商品链接状态和所属画板，标明另供下载的原图。多板任务按画板给设置、封面候选、缩略图和可复制稿，按需要合页或分开。主题词以编辑器可选项为准，字段和图片规范按当前官方帮助核对。局部修改交改动内容及必要对照。

对照试验按问题决定共用条件。独立创作用新图和新文案，比较文案可用同图。预览验收、受众表现和产品生图能力分别判断。

## 发布核验与持续维护

- **发布。** 核对当次授权、实际账号、画板和最终稿，按授权执行账号验证、建板、保存或发布。结果不明确时先按标题和图片查画板及已发布列表，有正式 Pin 就核验其公开链接。确认尚未发布才按授权重传，仍不明确则标待核验，草稿和正式链接分别记录。
- **读者页核验。** 逐条对照最终稿查主图、标题、描述、替代文字、画板归属和外链落点。替代文字未展示时可查公开页数据。承诺有成品时核对获取路径和文件规格，新增或修改画板时核对简介和封面。写清一致、差异、字段确认为空或待核验，修复后只复查受影响项。
- **记录与续更。** 交公开链接和读者侧结论，在现有交付记录、发布稿页和画板清单更新归属、链接、日期、证据和差异。区分候选、样稿、用户报告发布、账号内确认、人工验收和公开页核验。有数据后按相同发布时长比较展示量、收藏数、外链点击数和比率，结合最新趋势和新增用途决定是否追加。发布语言、实际受众地区和可归因的转化分别记录，小样本作线索。

定时任务按专项要求处理，恢复已停止的操作需有明确指示。

为 Flyne 的二次元艺术壁纸画板工作时，读 [Flyne 示例](references/flyne-quiet-worlds.md)。

维护技能时，按用户明确的长期要求更新通用流程。单次试验的数量、比例、工具和协作设置放在对应案例里。
