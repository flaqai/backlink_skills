# Pinterest 长期画板维护

结合指定品牌账号的风格和目标市场可核验的需求，围绕指定产品创作 Pin，按题材需要新建或续更画板。画板服务明确的读者需求，每条 Pin 给人独立的收藏理由和点进产品页后可尝试的操作。SEO 外链建设和真实读者访问同等重要。

每个环节交出下一步能直接使用的结果，相关内容可合在同一份方案、预览或记录里。按任务和证据选择调研、构图和制作方法。

## 启动任务

从本轮对话和项目记录明确任务目标、要做到哪一步及用户已定要求。为产品做内容时，记录适用的品牌或账号、目标画板或新建意向和目标产品页。能判断当前应交什么、可执行哪些操作，即可进入对应环节。在 Sean 工作区查 `AGENTS.md`、`pinterest/board-maintenance.md` 和 `pinterest/boards.json`，其他项目沿用自己的记录。影响当前步骤的缺项一次问齐。用户未定的地区、语言和风格可在调研后建议。参考作品、画板和 Pin 的数量，以及图片比例、制作方式和交付形式，按本轮要求和作品用途确定。

新选题进入调研与方案确认。只查市场、只交方案或只审查内容时，交对应结果。已确认的方案直接进入制作。局部修改沿用相关依据，按用户给定的范围修改和复核。已授权发布时，从核对账号、画板和最终稿开始。

可复制下面的模板，填入这次已知的信息。

```text
$pinterest-board-maintenance
品牌或账号【填写名称】
目标产品页【填写网址】
本次希望做到【查趋势／给画板和 Pin 方案／制作图文／验收或修改／发布】
其他已定要求【可选，如地区、语言、画板、条数或风格】
```

## 调研与选题

交出推荐题材、具体读者用途和支撑取舍的证据，注明会影响决定的缺口。记录实际来源，写清题材走势、单帖表现和画法参考各支持哪项判断。用浏览器调研时，尽量复用同一张标签页逐页查看，确需对照时再少量加开。

- **从作品定题。** 从 Pinterest 或小红书选适合目标画板的热门或精选作品，参考数量按选题需要定。美甲优先参考小红书等社交平台的爆款实拍，借鉴自然的手势、取景和光线。可围绕一个主参考做同题版本，也可用多条作品相互印证或组合内容。沿用有效的题材、呈现结构和收藏用途，做本账号的版本。记录可核实的单帖互动，平台精选和题材走势分别标明。用小红书样本时，在目标市场的 Pinterest 快查同类作品或关键词。自有或许可覆盖本次用途的素材可直接适配，其他样本用自己的设计重新生成。
- **查四类依据。** 新选题调研和完整提案都要涵盖目标地区的 **Top monthly trends**（月度搜索规模）、**Trends in the spotlight**（平台显示的收藏走势）、**Moments**（活动时机及升温、回落阶段）和 **Pinterest 社区**（创作者或平台人员分享的做法，并用同用途 Pin 核对）。说明各来源怎样影响选题、先后或画法。缺数据或与本题无关时写明原因。开放找题先看未筛选的全类目月榜，优先核对高位或有多个相关词的热点，再用全类目上升榜（Growing trends）补查新热点。用户限定题材时在其范围内核对。未指定市场时，选有依据的 Pinterest 主要用户地区。
- **核对近期走势。** 用同地区、同时间窗口和同筛选口径的周月变化或近期曲线判断升温、见顶或回落，区分实际数据与预测。判断具体哪天出现转折时，引用可复核的曲线或带日期的数据。分别核对用途或时机不同的细分词，全年榜和历史曲线用于了解长期表现与季节性。优先读原生数据，必要时在获授权的工作浏览器里只读核验。数据取不到时，写明缺口和待核验的判断。实际搜索量和转化需要独立证据。
- **查看同用途作品。** 从实际 Pin 判断读者在找成品、灵感还是方法，具体想保存、比较或复刻什么。需要判断需求的普遍程度时，对照不同作者的作品。续更时有可比旧作就一并查看。观察小图里先看到什么、取景怎样交代关键细节、哪些元素会抢走注意力。细分词没有曲线时，可引用上一级主题的走势并注明缺口。站内依据不足时，可提试稿并写明待验证的用途。
- **把参考用进画面。** 查与题材相关的成熟制图经验，优先看官方创作指南、创作者的制作过程或从业者的一手经验。提取会改变本轮取景、光影、材质或题材结合的具体做法。发现参考中的用法和预想有冲突时，调整选题或画法。用账号风格做原创设计，保留读者想收藏的用途，并核对目标产品页支持读者点击后要尝试的动作。同批复用有效的产品、画板、受众和制图依据，只补会改变选题或画面判断的缺口。 [Pinterest 创作指南](https://create.pinterest.com/en-gb/fundamentals/)
- **候选对照。** 开放找题时，结合月榜、上升榜、焦点收藏和节日节点，尽量找全用户范围内的近期热点。主动找原有题材和画板之外能与账号、产品结合的方向。同一用途的近义词归为一组，用途或时机不同的方向单列，和原有方向及用户点名的题材一起比较。逐组写明榜别、代表词和近期走势，有月榜数据时列出同一口径下的排名和搜索量指数。能结合的方向写出具体 Pin 的画面、收藏用途和可承接的画板。
- **取舍与查漏。** 因时机暂缓时，写对应细分词的近期走势。因用途或画板匹配暂缓时，写明读者需要的形式、试过的结合点，以及核对过的画板简介或旧作。资料不足时标为待核验并写明缺口。提交开工方案前，结合可取得的当期榜单和画板记录，对照候选表与拟做清单，把遗漏的可做方向补进拟做清单，并给出具体 Pin。
- **先覆盖方向，再定数量。** 按月榜需求、近期走势、账号风格和产品能承接的用途比较各类候选。开放选题时，在用户给定范围内，把调研发现的可做方向都列入同一份开工方案的拟做清单。可做方向有需求依据、时机合适，且产品能提供具体帮助。适合探索的可同案列为试做，写清要验证什么。拟做条数宁多勿少，把可行且各有独立收藏理由的构思写成具体 Pin。按读者用途决定新建或续更及各板条数，再按时机和读者收益排制作顺序。用户限定数量或制作条件有限时，说明哪些候选暂缓及理由。读者是否愿意点开，用发布后的点击数据判断。
- **画板方向。** 按读者用途比较新建与续更。热点能发展成服务同一类读者、各有收藏理由的一组新 Pin 时，提出新的画板主题和视觉方向。续更候选要核对已有画板的主题和用途，包括原拟画板之外的选项。用户指定画板或新建、续更方式时，按其范围执行。

## 开工方案与确认

交出确认后可直接制作和验收的方案。写清读者能得到什么、画面必须呈现什么，以及读者从 Pin 如何取得成品或进行下一步。

从参考作品试做时，提案写两项。**参考作品**给用到的原帖链接或可定位的精选卡片，附实际依据。**我们的版本**写保留哪项核心内容、准备做成什么样、归入哪个画板，按用途说明读者怎样取得成品或试做。第三方原图用于成稿或生图时，附适用许可。

在同一份开工方案汇总四类来源的关键发现和取舍，列出拟做的 Pin、画板、条数、制作顺序和本轮做到哪一步。发给用户确认的摘要也写明各类依据怎样影响决定，说明社区经验具体用在哪条 Pin 或哪项共用画法。新画板写清独立用途、名称、可直接使用的简介、封面方向和共同画风，续更说明如何接上旧作。从用户给定的风格、已核实的品牌作品或官方产品示例提取可辨认的画面特征，注明依据。新尝试的画风标为本轮提议。各画板按读者用途选择画法。

完整方案逐条写清以下内容，共用的依据集中说明，呈现形式按题材和任务规模决定。

1. **收藏后怎么用。** 写具体用途，附支持它的同用途作品。交成品时，写清规格和读者怎样取得。提供灵感或创作引导时，写清读者能借鉴哪一处。
2. **参考怎样用进本图。** 写明从案例或制图经验借了哪项做法，怎样结合账号风格改成自己的画面，并附原始链接。
3. **第一眼要看到什么。** 写清主体、缩图看点和放大后要核对的细节。用本图可见的取景、光色、材质或其他特征体现品牌画风，说明和同板其他作品的差别。
4. **为什么值得点开。** 写清读者点进产品页能多得到什么、从哪一步开始，核对目标页支持这一步。比如看到窗绘样图后，用自家窗照试换图案位置。

同批有相近构思时并排比较，续更时对照可比的旧作。每条都应有独立的收藏理由，缩图时也有可辨认的看点。相近的先从镜头、光色、质感或设计拉开。开放找题时，附可取得的当期月榜及实际用到的榜单，记录地区、查阅日、数据截止日、关键词、筛选条件和原始链接。实时链接无法复现引用的数值时，附可取得的截图或导出。取不到的写明缺口，相关判断保留待核验。社区周报、旧报告或零散作品可作趋势线索。

用户确认方案后，开始正式制图、写文案或交办制作。确认的是读者用途、应看见的特征和明确限制，制作时可据效果调整构图和表现手法。新增、替换或增加条数超出原确认范围时，把涉及的画板、条目和依据交用户确认变动部分。已确认的内容按原方案继续。

## 制作、主控验收与交付

制作交本轮可打开、可取用的图片和适用的文案，标清不同版本的用途。主控按提案交可查看的实际预览和简短结论，有修订时附必要对照。

1. **制作主图。** 按已确认的读者用途、第一眼看点和可见要求制作，按需要选择构图、光色、动作、材质和工具。美甲优先用自有或获准修改和发布的实拍图做底图，只在甲面局部换色或改纹样，保留原有手型、甲形、皮肤纹理和光影。图上文字服务作品用途。
2. **准备文案。** 画板名和简介说清用途。标题用读者熟悉的话点出画面或用途，自然带入贴题的搜法。描述按作品补配色、用法或做法，适用时带出产品能帮读者试的动作。主题词按内容选择。名称、简介、标题和描述默认省略品牌名，文案对照成图定稿，替代文字写图中可见的内容。提示词、操作建议和其他材料按需要提供。若给变体，写清改哪里、可见差别及相关约束。按实际来源标注样图，功能、费用、生成结果和商用等说法要有证据。产品网址只填 Pin 编辑器的 Link 字段，商品标签按实际适用性处理。
3. **主控验收。** 沿用开工方案查看最终上传图，逐张判断信息流大小的看点、放大后的品牌特征、细节、结构和裁切。有多张时并排看，有可比旧作时一并查看。从预览核对文案、替代文字和目标 Link 与收藏用途、点击收益是否一致，验证读者取得成品或开始操作的路径。留待公开页核验的事项标为待核验。看点弱或相近时，调整构图、光色或设计。局部修图做同尺寸前后对照。美甲图放大核对手型是否保留、甲缘是否贴合、反光是否顺着甲面弧度。其他局部修改核对相关字段和直接影响。同步稿源、预览和受影响字段，从用户实际查看的入口核对。标题、画板名或系列标记改动时，一并检查图上文字和替代文字。
4. **交最终稿。** 完整图文任务分字段提供上传图、标题、描述、替代文字、主题词候选、目标 Link、商品链接状态和所属画板。标清上传图和供下载的原图。主题词以编辑器实际可选项为准，字段限制或图片规范按当前官方帮助核对。多画板任务按画板列出设置、封面候选、缩略图和各 Pin 的完整可复制稿，按审阅和发布需要合页或分开。局部修改交改动后的内容和需要的对照。

用户要求对照试验时，按比较目的确定共用条件和要变化的内容。测试独立创作时各自用新图和新文案，测试文案变化时可用同图。把本地验收、实际受众表现和产品生图能力分别判断。

## 发布核验与持续维护

发布后交公开 Pin 链接和读者侧的核验结论。对照最终稿和提案的用途记录已确认的结果、差异及待核验项。有可比较的表现数据后再给维护建议。

- 发布前核对当次授权、实际账号、目标画板和最终稿。窗口已打开或账号已登录仅说明浏览器或账号就绪。账号验证、创建画板、保存和发布按当次授权执行。
- 上传或发布结果不明确时，重传前先查目标画板和账号已发布列表，用标题和图片确认是否已有同一条正式 Pin。找到就用其公开链接核验。确认尚未发布才按当次授权重传，仍无法判定时标记待核验。正式链接和遗留草稿分别记录。
- 拿到公开链接后，逐条从读者页对照最终稿，一次核对实际主图、标题、描述、替代文字、画板归属和外链落点。承诺可取得成品时，从读者侧核对领取路径和实际取得的文件规格。新建或修改画板时，一并核对简介和封面。界面未显示替代文字时，查该 Pin 公开页返回的数据，并与最终稿比对。区分读回一致、存在差异、字段确认为空和无法核验。修复后只复查受影响的 Pin 或画板字段。
- 在现有交付记录中按 Pin 编号登记公开链接、发布日期、核验范围和差异，再同步到发布稿页面和画板清单，更新正式画板名、链接、归属与维护日期。区分候选、样稿、用户报告发布、账号内确认、人工验收和公开页核验。证据不足的字段留空或标待核验。
- 有发布数据后，用相同发布时长比较，列出展示量、收藏数、外链点击数和相应比率。决定是否追加时，结合最新走势、同龄发布表现和新内容的看点。站内使用只在能可靠归因时报告。小样本只作线索。发布语言、实际受众所在地区和转化分别记录。
- 按用户当次任务维护，定时任务按专项要求处理，恢复此前已停止的操作需有明确指示。

为 Flyne 的二次元艺术壁纸画板工作时，读 [Flyne 示例](references/flyne-quiet-worlds.md)。

维护技能时，按用户明确的长期要求更新通用流程。单次试验的数量、比例、工具和协作设置放在对应案例里。
